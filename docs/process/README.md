# How Kaagaz was built

These are the working files from the build, kept as they were so the process can be checked.

- [`KAAGAZ_SPEC.md`](KAAGAZ_SPEC.md): the full spec the AI coding agent worked from.
- [`PROGRESS.md`](PROGRESS.md): the checklist, ticked only when a check had passed.
- [`DECISIONS.md`](DECISIONS.md): every decision made during the build, one line each, with the reason.
- [`FINAL_REPORT.md`](FINAL_REPORT.md): the report written at the end of the first build, with the verify output.

The rules the agent had to follow in every session are in [`../../CLAUDE.md`](../../CLAUDE.md).
