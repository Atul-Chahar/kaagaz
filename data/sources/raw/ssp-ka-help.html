Viewing Information in Various File Formats

The information provided by this Web site is available in various formats, such as Portable Document Format (PDF), Word, Excel, PowerPoint, and HTML. To view these files properly, your web browser requires the corresponding plug-ins or viewer software.

If your system lacks the required applications, you can download the free viewers and compatibility tools from the official links listed below.

Required Plug-ins & Viewers

Portable Document Format (PDF)

.pdf

Requires Adobe Acrobat Reader or a modern browser with built-in PDF viewing capabilities.

Adobe Acrobat Reader

Word Files

.doc / .docx

Viewable using Microsoft Word, Word Viewer, or LibreOffice Writer.

Word Viewer (till 2003) Office Compatibility Pack (2007+)

Excel Spreadsheets

.xls / .xlsx

Viewable using Microsoft Excel, Excel Viewer, or spreadsheet software.

Excel Viewer 2003 Office Compatibility Pack (2007+)

PowerPoint Presentations

.ppt / .pptx

Viewable using Microsoft PowerPoint or PowerPoint Viewer toolkits.

PowerPoint Viewer 2003 Office Compatibility Pack (2007+)

Flash / Interactive Content

.swf / .flv

Interactive vector graphics or video streams requiring browser extensions.

Adobe Flash Player
